# Clicker Game

[![Live demo](https://img.shields.io/badge/demo-live-19336e?style=flat-square)](https://hellenicdev.eu/clicker-game/) [![License: BSD 3-Clause](https://img.shields.io/badge/license-BSD%203--Clause-blue?style=flat-square)](LICENSE)

A simple incremental clicker game where every click counts.

**Play it live:** <https://hellenicdev.eu/clicker-game/>

## Features

- Click to earn points
- Five upgrades: Double Points, Auto-Clicker, Triple Points, Bonus Multiplier and Instant Click
- Progress is saved in your browser (localStorage)
- Works with mouse, touch and keyboard

## How to play

- Click the big button to earn points
- Buy upgrades once you can afford them to earn faster
- Your score and upgrades are kept when you come back

## Run locally

No build step. Serve the folder with any static server:

```sh
git clone https://github.com/hellenicdev/clicker-game.git
cd clicker-game
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
